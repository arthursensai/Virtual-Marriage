# حفل زفاف ودّي ثلاثي الأبعاد (Next.js + Supabase Realtime)

تطبيق Next.js يُقيم حفل زفاف ودّيًا أونلاين: شخصيات ثلاثية الأبعاد بأزياء مخصّصة، وغرفة حيّة يدخلها الضيوف من هواتفهم ويظهرون كشخصيات داخل المشهد، ويصفّقون ويرسلون تهاني في نفس اللحظة.

## كيف يعمل
- **العريس** ينشئ غرفة برمز من 6 خانات، وهو من يقود الحفل ويضغط "التالي".
- **العروس** تدخل برمزها السرّي (رابط `/join?code=…` يراه العريس فقط) لتخصّص مظهرها وتقول "قبلتُ" وتوقّع من هاتفها. وإن لم تنضم، يستطيع العريس أن يملأ بياناتها وتوقيعها بنفسه.
- **الضيوف** يدخلون برابط الغرفة، يكتبون أسماءهم ويختارون مظهرهم (رجالي/نسائي، ألوان، إكسسوارات)، فتظهر شخصياتهم مصطفّة على جانبي الممشى، ويرسلون 👏 ❤️ 🎉 وتهاني نصّية.
- كل ما سبق يعمل عبر **Supabase Realtime** (Presence + Broadcast) بدون أي جدول أو قاعدة بيانات.
- حالة الحفل (المرحلة ووقت بدئها) يبثّها العريس، فمن ينضم متأخرًا يرى المشهد في مكانه الصحيح.

## التشغيل محليًا
0. شغّل `supabase/migration.sql` في SQL Editor (ثم `002_wife_default_look.sql` إن كنت شغّلت النسخة الأولى سابقًا).
1. أنشئ مشروعًا في [Supabase](https://supabase.com) (المجاني يكفي).
2. من *Project Settings → API* انسخ **Project URL** و **anon public key**.
3. انسخ `.env.example` إلى `.env.local` وضع القيمتين فيه.
4. إن ظهر خطأ اتصال، افتح *Realtime → Settings* وفعّل **Allow public access**.
5. شغّل:
   ```bash
   npm install
   npm run dev
   ```
6. افتح `http://localhost:3000` واضغط "أنشئ غرفة الحفل". من لوحة "الحفل" انسخ رابط الضيوف ورابط العروس وأرسلهما.

## النشر على Vercel
1. ارفع المشروع إلى GitHub واستورده في Vercel.
2. أضف المتغيّرين `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` في *Environment Variables*.
3. انشر، ثم افتح الرابط وأنشئ غرفتك.

## ملاحظات مهمة
- **المصادقة**: بريد وكلمة سر عبر Supabase Auth. الأدوار تُحدَّد في الخادم (`supabase/migration.sql`)، ورمز العروس سرّي وصالح لمرة واحدة. شارك رمز الضيوف بحرّية ورمز العروس معها وحدها.
- الغرفة تنتهي عندما يغادرها الجميع (لا يُحفظ شيء في قاعدة بيانات).
- توقيت الحفل مبني على ساعة جهاز العريس؛ إن كانت ساعة أحد الضيوف مضبوطة خطأً بفارق كبير فقد يرى المشي متقدّمًا أو متأخرًا قليلًا.
- الحفل ترفيهي، والشهادة الناتجة لا قيمة قانونية لها.

## بنية المشروع
```
app/                 صفحات Next.js (الرئيسية + /room/[code])
components/          واجهة الغرفة (RoomClient) والمشهد (Stage) ولوحة المظهر
lib/scene.ts         مشهد three.js: القاعة، القوس، الكاميرا، حركة الحفل
lib/characters.ts    بناء الشخصيات والأزياء والإكسسوارات
lib/useRoom.ts       الاتصال بـ Supabase Realtime (Presence/Broadcast)
lib/derive.ts        بناء الحالة المشتركة من حالة المشاركين
```
