# ملفات موسيقى الحفل

ضع ملفات mp3/ogg المرخّصة هنا داخل المجلد المناسب:

- `ceremony/`   → موسيقى دخول العروسين وخلفية العقد
- `first-dance/` → الرقصة الأولى
- `party/`      → موسيقى السهرة
- `special/`    → مقطوعات خاصة (قطع الكعكة، إلخ)

الأسماء المتوقعة معرّفة في `lib/music/tracks.ts` (حقل `url`). عدّل ذلك الملف
إذا استخدمت أسماء أو مسارات مختلفة.
